# Glassmorphism Dashboard Cards in Oracle APEX

Modern Glassmorphism-style Dashboard Cards created in Oracle APEX using Dynamic Content Region and Pure CSS.

## Features

- Glassmorphism UI Design
- Frosted Glass Blur Effect
- Responsive Dashboard Cards
- Smooth Hover Animation
- Modern Gradient Background
- Lightweight Implementation
- No External Plugins Required

## Technologies Used

- Oracle APEX
- Dynamic Content Region
- HTML
- CSS
- JavaScript

## Implementation

This project uses:

- Dynamic Content Region Type to generate custom dashboard card structure
- CSS backdrop blur and transparency effects to achieve Glassmorphism design
- Simple HTML markup for flexible card layouts

## Preview

Modern dashboard cards with:

- Transparent glass effect
- Blur background
- Rounded corners
- Soft shadows
- Hover interactions

## Installation

1. Create a Dynamic Content Region in Oracle APEX
2. Add the HTML structure inside the region source
3. Copy the CSS into Inline CSS or Page CSS
4. Run the page
